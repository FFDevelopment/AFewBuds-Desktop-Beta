AFewBuds Desktop 0.16.0-beta.6

Furniture editing now supports mouse and controller toolbar selection.

- Tab switches between camera aiming and a free cursor.
- Y/Triangle or the D-pad opens furniture controls on a controller.
- D-pad selects a button; A/Cross activates it; B/Circle returns to aiming.
- Camera movement pauses while using controls, preserving the targeted furniture.
- X/Square picks up selected empty furniture while in layout aiming mode.
- Includes the complete textured desks and placement fixes from beta.5.

Open the AFewBuds launcher to update automatically.
