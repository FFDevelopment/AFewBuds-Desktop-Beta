AFewBuds Desktop 0.16.0-beta.7

Desktop catch-up release from verified AFewBuds 3D prototype source 76ea298fd5d888f6632003b7fe474e58c36cb4d1.
Desktop CI: https://github.com/FFDevelopment/afewbuds-3d-prototype/actions/runs/37871874150 (full regression tests and Windows/Linux exports passed).

- Keep apartment and purchased-house operations separate. House computers now display house-specific employees, stock, business summaries, equipment and bills rather than apartment data.
- Support explicit worker transfers between properties without automatically moving inventory, rented-property equipment, or apartment door-manager assignments.
- Sync each property's grow-room controls to its installed tents, grow lights and ventilation equipment instead of assuming the apartment's starter installation.
- Fix work-station animation states for Kobi, Malik and Rod: walk while travelling, stand normally at packing, grow, storage and other stations, and preserve the corrected couch sitting pose.
- Restore scissors trimming and progressive 3g / 7g bagging for upgraded benches, plus placed-bench bud pile and scale-weight displays.
- Preserve free-movement furniture placement, detailed object previews, controller/mouse editing, wall stashes, closer wall placement, property-specific storage and cloud-career sync.

This is a Windows and Linux desktop beta. Use AFewBuds-Launcher.exe on Windows for verified updates, or download a complete platform ZIP. Existing career saves and account files are not intentionally reset. Public mobile beta is a separate release.
